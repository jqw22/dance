    ⚙ GitHub sync setup

    Your links live in links.json in the GitHub repo below. This page reads that file on every load and writes your changes back to it — so a link added on your phone shows up on your laptop, and vice versa. To save changes you need a GitHub token, which is stored only in this browser (never uploaded anywhere but GitHub).

    Create one at github.com/settings/personal-access-tokens — a fine-grained token with access to only this repo and Contents: Read and write.
